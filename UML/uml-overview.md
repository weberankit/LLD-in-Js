1. UML Overview
What is UML?
UML stands for Unified Modeling Language.

UML is a standardized visual modeling language used to represent the structure, components, objects, relationships, and interactions of a software system.
Types of UML Diagrams
UML diagrams are broadly divided into two categories.
Category	Focus	Example
Structural	Static structure	Class diagram
Behavioral	Dynamic interactions	Sequence diagram


Structural UML Diagrams
Structural diagrams describe the static structure of an application.

They answer questions such as:
- Which classes and components exist?
- What attributes and methods do they contain?
- How are classes connected?
- What relationships exist between different components?

Structural diagrams focus on how a system is organized rather than the order in which operations execute.
Behavioral UML Diagrams
Behavioral diagrams describe the dynamic behavior of an application.

They answer questions such as:
- How do objects interact?
- Which object sends a message to another object?
- Which methods are called?
- In what order do interactions occur?
- How does the system respond to operations?
In object-oriented programming (OOP), object interaction often means one object calling another object's method or sending a message.
